# Export symbol allowlist for libtetherkitnext.dylib (-exported_symbols_list).
#
# Only the C ABI is exported. C++ symbols (mangled names of tetherkitnext::*, the static copy of libusb) are all
# hidden, for two reasons:
#   1. The host process may already have another libusb loaded, and exporting identically named symbols would let the two pollute each other;
#   2. C++ symbols carry an ABI fingerprint; once leaked they amount to a promise of stability, and we only want to
#      promise the tetherkitnext_c.h layer.
#
# The leading underscore is Mach-O's C symbol naming convention (C's tk_version -> _tk_version).
_tk_*
